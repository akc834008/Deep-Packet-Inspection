# Deep Packet Inspection (DPI) System

A Deep Packet Inspection (DPI) system that analyzes network traffic by inspecting packet headers and payloads to identify protocols, classify traffic, and monitor network activity. This project demonstrates core concepts of computer networks, packet processing, and network security.

---

## 🚀 Features

- Deep Packet Inspection (DPI)
- Packet parsing from PCAP files
- Protocol detection and classification
- Connection tracking
- Rule-based traffic filtering
- Network traffic analysis
- Multi-threaded packet processing
- Fast-path packet optimization

## ⚙️ How It Works

1. Reads packets from a PCAP file.
2. Parses Ethernet, IP, TCP, and UDP packets.
3. Inspects packet payloads for protocol identification.
4. Tracks network connections.
5. Applies filtering rules.
6. Generates traffic analysis results.
